## 🛠️ Tech Stack

- **Framework:** React 19 • Vite 6 • TypeScript Strict
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion 12 • HTML5 Canvas Particle Engine
- **Icons:** Lucide React
- **Audio:** Web Audio API Procedural Synthesizer
- **Hosting:** Vercel Edge
